Tasmania LIST open data, cloud-ready

Every statewide dataset from the LIST open data bulk downloads, as GeoParquet and Cloud Optimized GeoTIFF on Source Cooperative. Nothing to download first: read any of it in place over HTTPS or S3, with DuckDB, GDAL, R, Python or QGIS.

Built from LGAs. Where LIST ships a product only as 29 per-LGA zips, the statewide file here is built from them: features LIST clipped at LGA boundaries are rejoined to one row per feature id, and an lga column names the source LGAs. The per-LGA files are in the store too, under <product>/<lga>/. Details in the store README.
